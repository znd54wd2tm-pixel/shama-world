# SHAMA WORLD V6

V6 — UI/UX upgrade поверх существующей premium-версии.

## Что изменено
- Интерактивный 3D город SHAMA WORLD на вкладке «Мир».
- Свайп/drag по городу, pinch/wheel zoom и reset.
- Кликом по 3D-районам можно переходить в соответствующие разделы.
- Добавлена фотография города как дальний 3D-слой, но интерфейс не является просто картинкой.
- Реальные фотографии кейсов из предоставленного материала.
- Реальные фотографии предметов для ключевых коллекционных предметов.
- Улучшена анимация открытия кейса: глубина, photo-art, cinematic reveal.
- Апгрейдер переработан: статичное колесо, вращается только стрелка.
- Серверный результат остаётся авторитетным: SUCCESS/FAIL приходит только от backend.
- Исправлена геометрия попадания стрелки в success/fail зоны.
- Sticky premium header и улучшенная mobile/safe-area обработка.

## Backend
Не менялась модель авторизации и существующие API.
Telegram WebApp initData, SQLite, кейсы, инвентарь, экономика, рынок, заработок, профиль и upgrade сохраняются.

## Render
Build: `pip install -r requirements.txt`
Start: `uvicorn routes:app --host 0.0.0.0 --port $PORT`

BOT_TOKEN хранится только в Render Environment Variables.
