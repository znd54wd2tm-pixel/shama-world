CASE WORLD — Telegram Bot v1.0

1. Открой @BotFather в Telegram и создай бота через /newbot.
2. Скопируй токен.
3. Открой config.py и замени ВСТАВЬ_ТОКЕН_БОТА_СЮДА на свой токен.
4. Установи Python 3.10+.
5. В терминале открой папку проекта.
6. Выполни:
   pip install -r requirements.txt
7. Запусти:
   python bot.py

После запуска открой своего бота в Telegram и отправь /start.

В проекте пока есть:
- регистрация пользователей;
- SQLite база;
- баланс CW;
- ежедневный бонус;
- профиль;
- заготовки кейсов;
- заготовка инвентаря;
- заготовка рейтинга.

Следующий этап: полноценная система кейсов и предметов.
