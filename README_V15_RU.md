# SHAMA WORLD V15

Это обновление существующего проекта из `shama-world-main.zip`. FastAPI, SQLite,
Telegram, SHAMA WORKS, банк, апгрейд и прежний SH MARKET сохранены.
`$` в интерфейсе означает исключительно виртуальную игровую валюту. Числовые
остатки старой валюты не конвертируются и не обнуляются; вывода в реальные деньги нет.

## Обновление действующего сервера

1. Остановите приложение на время обновления. Сохраните используемые `.env` и базу.
2. Замените исходники файлами архива, сохранив свой `.env` и прежний `DATABASE_PATH`.
   Рабочей базы и секретов в поставке нет.
3. Используйте Python 3.12.14 из `.python-version` и установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   python manage.py migrate
   python manage.py validate
   ```

4. Запускайте прежней командой:

   ```powershell
   python -m uvicorn routes:app --host 0.0.0.0 --port 8000
   ```

   На Render сохраните команду и `PORT` из `render.yaml`; persistent disk и
   `DATABASE_PATH=/var/data/shama_world.db` остаются обязательными. Отдельный бот
   не нужен, если используется уже существующий запуск polling через FastAPI.

При первом применении V15 существующая SQLite копируется через SQLite Backup API
в `backups/<имя>.before-v15.<UTC-время>.sqlite3` рядом с базой. Проверяется целостность
копии. Миграция добавляет таблицы и поля, сохраняя прежние идентификаторы и данные.
При восстановлении Supabase сначала возвращаются сохранённые данные, затем
добавляются отсутствующие позиции каталога. Некорректное восстановление откатывается.

## Локальная проверка

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python routes.py --dev --port 8765
```

`--dev` — прежний явный локальный режим без Telegram. На сервере используйте
`routes:app`, где подпись и срок действия Telegram initData проверяются обязательно.
Для нового локального окружения можно скопировать `.env.example` в `.env`;
при обновлении действующего проекта его `.env` заменять не нужно.

Браузерные сценарии: `tests/browser-smoke.cjs` и `tests/browser-edgecases.cjs`.
Они требуют Node.js, `playwright`, установленный браузер и локальный тестовый сервер.
Настройки: `PLAYWRIGHT_MODULE`, `BROWSER_PATH`, `SHAMA_TEST_URL`. Скрипты допускают
только адреса localhost/127.0.0.1. Используйте отдельную тестовую БД, пополните баланс
локального пользователя и добавьте кофейню для сценария отображения предприятий.
Создайте `.test-data` перед запуском — туда сохраняются снимки и результаты проверок.
Готовую изолированную фикстуру можно создать командой `python tools/prepare_browser_test.py`;
запускайте тестовый сервер с `DATABASE_PATH`, указывающим на `.test-data/browser.sqlite3`.
Three.js включён локально, npm-сборка для приложения не требуется.

## Что появилось

- Кнопки «Открыть 1 за $N» и «Открыть 10 за $N», единый серверный розыгрыш,
  одно списание за пакет, десять отдельных сохранённых наград.
- История открытий и восстановление потерянного ответа по идентификатору запроса.
- Молния вверху окна: серверная настройка быстрого режима, точные уведомления,
  мгновенный показ сохранённых результатов. Изначально быстрый режим выключен.
- Обычный режим: Three.js, падение и отскок кейса, приближение камеры, крышка и свет,
  затем трёхсекундная лента с остановкой на серверном предмете. Около пяти секунд
  на результат после ответа сервера; для пакета — последовательные открытия с пропуском.
- Выбор отдельных результатов, продажа выбранных или всех, сохранение,
  переход поддерживаемых предметов в существующий апгрейд с очередью выбора.
- 35 новых предметов, отдельные векторные изображения, 6 дополнительных обычных
  кейсов. Прежние 5 кейсов, предметы, цены, вероятности и идентификаторы сохранены.
- 3 бизнес-кейса, 9 типов предприятий, покупка предприятия напрямую, сотрудники,
  менеджеры, зарплаты, улучшения, 5 уровней и остановка/возобновление.
- Объявления предметов и предприятий в прежнем SH MARKET. Эскроу предмета,
  отмена объявления, атомарная покупка, комиссия 5%, передача предприятия с персоналом.
- Чёрно-золотая палитра; фиолетовый свет прежних иллюстраций перекрашен,
  исходные позиции каталога сохранены.

## Параметры, дополняющие пропуски ТЗ

Пользователь разрешил выбрать отсутствующие значения. Они вынесены в
`game_config.py`, а не скрыты в клиенте. Существующие пулы обычных кейсов хранятся
в `case_drops` и не перезаписываются при запуске. Новые пулы первично заполняются
из конфигурации; их можно редактировать в SQLite или применить изменения явно:

```powershell
python manage.py backup
python manage.py apply-config
python manage.py validate
```

Перед `apply-config` остановите приложение. Команда делает резервную копию,
закрывает прежний период работы предприятий и меняет только добавленные каталоги
предприятий и кейсов. Прежние обычные кейсы не затрагиваются.

### Бизнес-кейсы

| Кейс | Цена | Предприятия и вероятности |
|---|---:|---|
| BUSINESS CASE | $20 000 | Кофейня 60%; Автомойка 25%; Мастерская 12%; Пекарня 3% |
| BUSINESS ELITE CASE | $100 000 | Пекарня 50%; Ресторан 30%; Логистический центр 15%; Отель 5% |
| BUSINESS IMPERIAL CASE | $250 000 | Логистический центр 55%; Отель 30%; Технологическая компания 12%; Промышленный комплекс 3% |

Каждый пул даёт 100%. Один тип предприятия можно иметь в единственном экземпляре.
Повтор в том числе внутри пакета приносит 50% исходной цены предприятия;
уровень, улучшения и цена объявления в компенсации не участвуют.

### Предприятия

Выручка и расходы в таблице — базовые значения за час с персоналом, до бонусов и зарплат.

| Предприятие | Исходная цена | Выручка/ч | Расходы/ч | Рабочие места |
|---|---:|---:|---:|---:|
| Кофейня | $20 000 | $410 | $110 | 3 |
| Автомойка | $35 000 | $680 | $200 | 4 |
| Мастерская | $60 000 | $1 100 | $360 | 4 |
| Пекарня | $90 000 | $1 600 | $600 | 5 |
| Ресторан | $150 000 | $2 600 | $900 | 6 |
| Логистический центр | $240 000 | $3 800 | $1 400 | 7 |
| Отель | $350 000 | $5 500 | $2 200 | 8 |
| Технологическая компания | $500 000 | $7 800 | $3 000 | 9 |
| Промышленный комплекс | $750 000 | $11 000 | $4 500 | 10 |

- Без сотрудников: 50% выручки, 70% базовых расходов, зарплата $0, опыт ×0,5.
  Кофейня: $205 − $77 = $128/ч.
- Специалист: найм 1% исходной цены, зарплата 4% базовой выручки/ч, бонус +3%.
  Менеджер: с уровня 3, максимум один, занимает место; найм 3%, зарплата 8%, бонус +5%.
- Стоимости I/II/III каждого направления: 10%/20%/30% исходной цены предприятия.
  Эффекты оборудования и маркетинга: +5/+10/+15%; помещений: −5/−10/−15%;
  автоматизации: −3/−6/−10%. Значения уровней не суммируются между собой.
- Пороги опыта уровней: 0/4/12/36/72 часа работы с персоналом; бонусы уровня:
  0/+2/+4/+6/+8%. II улучшения — с уровня 2; III — с уровня 3,
  III автоматизации — с уровня 4; премиальная рамка — с уровня 5.
- Общий бонус выручки ограничен +50%; расходы не становятся отрицательными.
- Начисление происходит по серверным временным отметкам при входе/просмотре/действии.
  Закрытая Mini App не останавливает предприятие. Учитываются максимум 12 часов,
  остаток периода отсекается; повторный запрос не начисляет его заново.
- Расходы и зарплата оплачиваются из выручки периода. Если предприятие убыточно,
  разница покрывается балансом до его исчерпания, затем предприятие приостанавливается.
  Продажа, найм, увольнение, улучшение и смена статуса сначала закрывают прежний период.
- Балансы прежнего проекта целочисленные. Доли доллара дохода сохраняются в
  остатке предприятия и не теряются при частых запросах. Найм/зарплата и компенсация
  округляются вниз до целого доллара; комиссия 5% — до ближайшего целого, половины вверх.

## Ограничения проверки

Деплой и подключение к рабочей базе не выполнялись. Проверки произведены локально
на тестовых данных и мобильных размерах браузера. Реальное устройство с Telegram,
боевой BOT_TOKEN и рабочую Supabase нужно проверить после установки на вашем сервере.
3D-модели кейсов процедурные, изображения предметов векторные/существующие;
сторонние лицензируемые модели брендов не добавлялись.
